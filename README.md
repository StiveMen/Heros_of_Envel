# Герои Энвелла: Разлом — 2D

Фанатская мини-игра-платформер с оригинальной процедурной графикой.

## Быстрый запуск Windows
1. Установи Python 3.11 или 3.12 с python.org, включив **Add Python to PATH**.
2. Скачай репозиторий и распакуй его, если скачал ZIP.
3. Запусти `build_windows.bat`.
4. После сборки запускай `dist\Envel2D.exe`.

## Управление
- A/D или стрелки — движение
- Пробел / W / ↑ — прыжок
- J — магическая атака
- Esc — пауза
- Enter — начать / продолжить / перезапустить

Собирай кристаллы, избегай теневых существ и доберись до портала. Для победы нужно собрать минимум 5 кристаллов.

## Сборка EXE через GitHub Actions
Вкладка **Actions** → **Build Windows EXE** → **Run workflow**. После успешной сборки скачай артефакт `Envel2D-Windows` из запуска workflow.

Это неофициальный фанатский проект. Используются простые оригинальные спрайты, созданные кодом; официальные изображения и музыка сериала не включены.
