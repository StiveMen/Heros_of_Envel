# Герои Энвелла: Разлом

Фанатский пиксельный 2D-платформер, который работает прямо в браузере на **JavaScript + HTML5 Canvas**. Ничего устанавливать не нужно.

## Запуск игры
1. Открой репозиторий и нажми **Code → Download ZIP**, либо клонируй его.
2. Открой файл `index.html` в современном браузере.
3. Нажми **Enter**, чтобы начать.

Можно также включить GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**. После публикации игра будет доступна по ссылке GitHub Pages.

## Управление
- **A / D** или **← / →** — движение
- **Пробел / W / ↑** — прыжок
- **J** — магический снаряд
- **Esc** — пауза
- **Enter** — начать / продолжить / перезапустить
- На телефонах доступны экранные кнопки.

## Цель
Собери минимум 5 кристаллов, избегай теневых существ и доберись до портала в конце уровня.

## Файлы
- `index.html` — страница игры
- `style.css` — оформление и адаптивный интерфейс
- `game.js` — игровой движок на Canvas, физика, враги, кристаллы и эффекты

Старая версия на Python/Pygame и сценарий сборки Windows сохранены в репозитории, но для браузерной версии они не нужны.

Это неофициальный фанатский проект. Используются простые оригинальные пиксельные спрайты, созданные кодом; официальные изображения и музыка сериала не включены.
